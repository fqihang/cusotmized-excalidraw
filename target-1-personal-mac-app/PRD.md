# PRD: Personal Mac App

## MVP 范围

MVP 要把 Excalidraw 从“单个网页画布”包装成“本机个人白板资料库”。用户打开 App 后可以选择或创建一个本地 workspace，在左侧看到白板列表和缩略图，点击任意文件进入 Excalidraw 画布编辑；编辑过程自动保存为标准 `.excalidraw` 文件，并同步更新缩略图、标题、标签和搜索索引。

MVP 包含：

- Workspace 初始化：选择本地文件夹、创建 app 元数据目录、记住最近 workspace。
- Scene 管理：新建、打开、重命名、复制、删除到废纸篓、在 Finder 中显示。
- Excalidraw 编辑：嵌入上游画布组件，保留基础绘图、图片、文本、导出和快捷键。
- 自动保存：编辑变更 debounce 后保存，窗口关闭前 flush，保存失败时有明确状态。
- 缩略图：保存后异步生成 PNG 或 SVG 缩略图，用于列表和最近文件。
- 搜索/标签：按标题、标签、更新时间和提取出的文本元素搜索。
- 导入/导出：打开现有 `.excalidraw` 文件；导出仍保持 `.excalidraw`，另支持 PNG/SVG 由上游能力提供。
- Mac 基础体验：应用菜单、常用快捷键、拖拽打开文件、文件关联、离线可用。

## 非目标

- 不做云账号、订阅、团队空间或服务端同步。
- 不做多人实时协作、评论、分享链接和权限管理。
- 不重写 Excalidraw 绘图引擎、元素模型或文件格式。
- 不承诺首版支持 Windows/Linux；架构保留可移植性，但验收只看 macOS。
- 不做复杂数据库迁移系统；MVP 使用简单版本化 metadata，Pro 阶段再强化。
- 不做端到端加密同步；本地文件由 macOS 文件系统和用户磁盘策略保护。

## 关键用户流程

### 首次启动

1. 用户打开 Mac App。
2. App 提示选择或创建 workspace 文件夹。
3. App 扫描已有 `.excalidraw` 文件，生成初始索引和缩略图。
4. 用户进入资料库视图，能看到空状态或已有文件列表。

### 新建白板

1. 用户点击新建或使用 `Cmd+N`。
2. App 在 workspace 下创建一个未命名 scene 草稿。
3. Excalidraw 画布打开，用户开始绘制。
4. App 自动保存 `.excalidraw` 文件，生成标题、更新时间和缩略图。

### 打开和编辑已有白板

1. 用户从列表、搜索结果、最近文件或 Finder 双击 `.excalidraw` 打开。
2. App 用上游 `loadFromBlob`/restore 逻辑恢复 elements、appState、files。
3. 用户编辑后，`onChange` 触发自动保存。
4. App 更新索引、缩略图、脏状态和最近打开记录。

### 搜索和整理

1. 用户在资料库搜索框输入关键词或选择标签。
2. App 查询本地索引，匹配标题、标签、文件路径、文本元素内容。
3. 用户可批量加标签、收藏、复制或删除文件。

### 导出和兼容

1. 用户选择导出 PNG/SVG 或保存 `.excalidraw`。
2. PNG/SVG 走上游导出能力。
3. `.excalidraw` 文件保持标准 JSON，能被 Web 版 Excalidraw 打开。

## 验收标准

- 首次启动能创建 workspace，并在重启后自动恢复最近 workspace。
- 新建、打开、编辑、关闭、重启后，`.excalidraw` 内容无丢失，图片文件引用能恢复。
- 自动保存在连续绘制时不会阻塞画布；停止编辑 1 秒内落盘，退出前能 flush。
- Finder 中已有 `.excalidraw` 文件可导入或直接打开，保存后仍可被上游 Excalidraw Web/App 读取。
- 每个 scene 在列表中有标题、更新时间、标签和缩略图；缩略图失败不会影响文件保存。
- 搜索能匹配文件名、用户标题、标签和文本元素内容。
- App 在无网络状态下完成新建、编辑、保存、搜索和导出。
- 删除操作默认移入 macOS Trash 或 workspace trash，不直接永久删除。
- 保存失败、权限不足、文件被外部修改、格式无效时有明确错误提示和可恢复路径。
