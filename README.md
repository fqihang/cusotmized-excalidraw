# Customized Excalidraw

This repository contains the current customized Excalidraw work snapshot.

- `excalidraw/`: upstream Excalidraw source snapshot used as the base.
- `target-1-personal-mac-app/`: local-first macOS Personal Excalidraw app built with Tauri, React, Vite, and Excalidraw.
- `target-3-team-self-hosted/`: self-hosted/team planning documents.

Build artifacts, dependency folders, and local bundles are intentionally excluded from git.
